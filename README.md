# 荒野亂鬥賽事抽籤同步系統

這是一個給工作人員使用的即時同步抽籤與 BO3 星光戰計分系統。

## 功能

- 四強、季軍賽、冠軍賽皆支援 BO3 星光戰
- 每戰抽模式、禁圖、抽地圖
- 已使用模式會標記，不會在同一組 BO3 重複抽到
- 季軍賽與冠軍賽可從四強隊伍中選擇對戰隊伍
- 多位工作人員可同時連線，同步抽籤、禁圖、隊伍與勝場

## 本機啟動

```bash
npm start
```

或：

```bash
node server.js
```

開啟：

```text
http://localhost:8787
```

## 部署

這個專案可以部署到 Render、Railway、Fly.io、VPS 等可執行 Node.js 的平台。

啟動指令：

```bash
npm start
```

系統會優先使用平台提供的 `PORT`，沒有提供時預設為 `8787`。

## 注意

GitHub Pages 只能放靜態網站，不能執行 `server.js`，因此不適合用來做即時同步。建議把程式碼放 GitHub，再部署到可跑 Node.js 的平台。
